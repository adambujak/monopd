# Optional card images

Put your own card images here, then list them in `cards/skin.json`. The viewer uses an image for every card listed and keeps its built-in design for the rest. Everything in this folder except this README is gitignored, so the images stay on your machine.

```json
{
  "property-brown": "brown.png",
  "money-5": "5m.jpg",
  "back": "back.png"
}
```

- `action-deal-breaker` `action-just-say-no` `action-sly-deal` `action-forced-deal` `action-debt-collector` `action-it-s-my-birthday` `action-double-the-rent` `action-house` `action-hotel` `action-pass-go`
- `rent-green-darkblue` `rent-red-yellow` `rent-pink-orange` `rent-brown-lightblue` `rent-railroad-utility` `rent-wild`
- `money-1` `money-2` `money-3` `money-4` `money-5` `money-10`
